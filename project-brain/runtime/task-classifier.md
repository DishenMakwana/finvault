# Runtime: Task Classifier — Project Brain v2

## Responsibility
Classifies incoming user prompts to prevent analyzing unnecessary subsystems.

## Classifications
1. `AUTH`: Routes `login`, `register`, `Session`, `User`
2. `CASHFLOW`: Inflow, Outflow, Transaction, Categories, Cash Balance calculation
3. `LOANS`: Relative loans, repayments, promises, installment tracking
4. `HOUSES`: Properties, initial cash in hand
5. `EXPORT`: ExcelJS generation, spreadsheet columns, formulas
6. `UI_THEME`: Colors, Bento grids, Recharts, Framer Motion
