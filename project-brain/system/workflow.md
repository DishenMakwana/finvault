# Execution Workflow Lifecycle — Project Brain v2

```
Receive Prompt
      ↓
Task Classification
      ↓
Graph Retrieval (Find affected nodes)
      ↓
Context Loading (Select only relevant memory files)
      ↓
Planning & Verification Strategy
      ↓
Execution (Code implementation)
      ↓
Static Validation (Build & Typecheck)
      ↓
AI Review (Architecture, Security, Code Quality)
      ↓
Confidence Scoring (Score >= 90)
      ↓
Knowledge Synchronization (Incremental memory & graph update)
      ↓
Response
```

No stage in this pipeline may be skipped.
